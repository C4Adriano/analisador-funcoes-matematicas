# Glossary / Glossário

## English

A reference guide for terms used in this project — mathematical, technical, and related to GitHub.

---

### 📐 Mathematical Terms

**Asymptote**
A line that a curve approaches but never touches. In Exponential and Logarithmic Functions, the asymptote defines the boundary of the function's range.

**Coefficient**
A number that multiplies a variable in a function. In `f(x) = ax² + bx + c`, the coefficients are `a`, `b`, and `c`.

**Concavity**
Describes whether a Quadratic Function opens upward (happy face, `a > 0`) or downward (sad face, `a < 0`).

**Domain**
The set of all valid input values (`x`) for a function.

**Range**
The set of all output values (`y`) produced by a function. Also called *Image*.

**Root**
A value of `x` where `f(x) = 0` — that is, where the function crosses the X axis.

**Sign Study**
An analysis that determines for which values of `x` the function is positive, negative, or zero.

**Vertex**
The highest or lowest point of a Quadratic Function. Defined by the coordinates `(-b/2a, -Δ/4a)`.

**Slope**
Describes how steep a Linear or Exponential Function is. In a Linear Function, it is the coefficient `a` in `f(x) = ax + b`.

**Unknown**
A coefficient (`a`, `b`, or `c`) whose value is not given directly — the program calculates it from known points.

### 💻 Code Terms

**Object**
A JavaScript structure that groups related functions and variables together. This project uses objects like `config`, `helpers`, `algebra`, and `analisar` to organize the code.

**JS Function**
A block of reusable code in JavaScript that performs a specific task. Different from a Mathematical Function.

**`config`**
The object that stores all global program settings, such as decimal places, language, and Unicode preferences.

**`helpers`**
The object that contains common calculations and result assembly used across multiple function types.

**`algebra`**
The object responsible for mathematical calculations such as logarithms, natural log, and safe division.

**`analisar`**
The object that handles the analysis of each mathematical function type.

**`escrita`**
The object responsible for formatting, translating, and converting text for display.

**`ui`**
The object that manages user interaction — menus, inputs, and error display.

**`erro`**
The object that provides standardized error messages throughout the program.

**`prompt`**
A built-in browser dialog that asks the user to type a value. Used as the main input method in this project.

**`alert`**
A built-in browser dialog that displays a message to the user. Used to show results and menus.

**`NaN` (Not a Number)**
A JavaScript value that appears when a mathematical operation produces an invalid result, such as dividing zero by zero.

**`Infinity`**
A JavaScript value that appears when a number exceeds the maximum representable value, such as dividing by zero.

### 🐙 GitHub Terms

**Branch**
A parallel version of the repository. The main branch is called `main`.

**Changelog**
A file that documents all changes made across versions of the project. See [`CHANGELOG.md`](CHANGELOG.md).

**Commit**
A saved snapshot of changes in the repository. Each commit has a message describing what was changed.

**Fork**
A personal copy of someone else's repository, allowing you to make changes without affecting the original.

**Issue**
A report or suggestion submitted through GitHub. Can be a bug report or a feature request.

**Pull Request (PR)**
A proposal to merge changes from one branch into another. Used for code review and contributions.

**Release**
A published version of the project, marked with a version tag (e.g., `v6.0`).

**Repository**
The project folder hosted on GitHub, containing all files, history, and settings.

## Português

Um guia de referência para os termos usados neste projeto — matemáticos, técnicos e relacionados ao GitHub.

---

### 📐 Termos Matemáticos

**Assíntota**
Uma reta que uma curva se aproxima mas nunca toca. Nas Funções Exponenciais e Logarítmicas, a assíntota define o limite da imagem da função.

**Coeficiente**
Um número que multiplica uma variável em uma função. Em `f(x) = ax² + bx + c`, os coeficientes são `a`, `b` e `c`.

**Concavidade**
Descreve se uma Função Quadrática abre para cima (face feliz, `a > 0`) ou para baixo (face triste, `a < 0`).

**Domínio**
O conjunto de todos os valores de entrada (`x`) válidos para uma função.

**Imagem**
O conjunto de todos os valores de saída (`y`) produzidos por uma função.

**Raiz**
Um valor de `x` onde `f(x) = 0` — ou seja, onde a função cruza o eixo X.

**Estudo do Sinal**
Uma análise que determina para quais valores de `x` a função é positiva, negativa ou zero.

**Vértice**
O ponto mais alto ou mais baixo de uma Função Quadrática. Definido pelas coordenadas `(-b/2a, -Δ/4a)`.

**Inclinação**
Descreve o quão íngreme é uma Função Afim ou Exponencial. Em uma Função Afim, é o coeficiente `a` em `f(x) = ax + b`.

**Incógnita**
Um coeficiente (`a`, `b` ou `c`) cujo valor não é fornecido diretamente — o programa o calcula a partir de pontos conhecidos.

### 💻 Termos do Código

**Objeto**
Uma estrutura JavaScript que agrupa funções e variáveis relacionadas. Este projeto usa objetos como `config`, `helpers`, `algebra` e `analisar` para organizar o código.

**Função JS**
Um bloco de código reutilizável em JavaScript que realiza uma tarefa específica. Diferente de uma Função Matemática.

**`config`**
O objeto que armazena todas as configurações globais do programa, como casas decimais, idioma e preferências de Unicode.

**`helpers`**
O objeto que contém cálculos comuns e montagem de resultados usados em vários tipos de função.

**`algebra`**
O objeto responsável pelos cálculos matemáticos, como logaritmos, logaritmo natural e divisão segura.

**`analisar`**
O objeto que realiza a análise de cada tipo de função matemática.

**`escrita`**
O objeto responsável por formatar, traduzir e converter textos para exibição.

**`ui`**
O objeto que gerencia a interação com o usuário — menus, entradas e exibição de erros.

**`erro`**
O objeto que fornece mensagens de erro padronizadas em todo o programa.

**`prompt`**
Uma caixa de diálogo nativa do navegador que pede ao usuário que digite um valor. Usado como principal método de entrada neste projeto.

**`alert`**
Uma caixa de diálogo nativa do navegador que exibe uma mensagem ao usuário. Usado para mostrar resultados e menus.

**`NaN` (Not a Number / Não é um Número)**
Um valor JavaScript que aparece quando uma operação matemática produz um resultado inválido, como dividir zero por zero.

**`Infinity`**
Um valor JavaScript que aparece quando um número ultrapassa o valor máximo representável, como dividir por zero.

---

### 🐙 Termos do GitHub

**Branch**
Uma versão paralela do repositório. A branch principal se chama `main`.

**Changelog**
Um arquivo que documenta todas as alterações feitas ao longo das versões do projeto. Veja [`CHANGELOG.md`](CHANGELOG.md).

**Commit**
Um registro salvo das alterações no repositório. Cada commit tem uma mensagem descrevendo o que foi alterado.

**Fork**
Uma cópia pessoal do repositório de outra pessoa, permitindo fazer alterações sem afetar o original.

**Issue**
Um relatório ou sugestão enviado pelo GitHub. Pode ser um reporte de bug ou uma solicitação de funcionalidade.

**Pull Request (PR)**
Uma proposta para mesclar alterações de uma branch para outra. Usado para revisão de código e contribuições.

**Release**
Uma versão publicada do projeto, marcada com uma tag de versão (ex.: `v6.0`).

**Repositório**
A pasta do projeto hospedada no GitHub, contendo todos os arquivos, histórico e configurações.
