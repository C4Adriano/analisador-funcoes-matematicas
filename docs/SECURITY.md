## Português Brasileiro <a id="pt-br">(pt-BR)</a>

### Versões Suportadas

Apenas a última versão menor (_minor_) da versão principal (_major_) atual recebe atenção de segurança.

| Versão  | Suportada |
| ------- | --------- |
| 7.x.x   | ✅        |
| < 7.0.0 | ❌        |

### Versão Atual

Este **_Software_** atualmente roda inteiramente no navegador, sem servidor externo, sem dados do **Usuário** e sem conexões externas, portanto vulnerabilidades de segurança são improváveis.

Se encontrar algo na **Versão** atual, abra uma **_[Issue]_**. Por se tratar de um projeto mantido individualmente, aguarde até **14 dias** por uma resposta.

> **Obs.:** A inclusão de trechos de código em uma **_[Issue]_** deste repositório, estritamente para fins de relato ou discussão de uma vulnerabilidade, não é considerada uso, cópia ou distribuição do **_Software_**, conforme a [Seção 4][Licença-§4] da **[Licença]**, que também define os limites dessa exceção.

### Versões Futuras

**Versões** futuras poderão incluir contas de **Usuário** e armazenamento de dados.
Quando isso acontecer, esta política será atualizada — e vulnerabilidades
envolvendo dados do **Usuário NÃO** devem ser reportadas publicamente.

Até lá, em caso de dúvida, entre em contato diretamente com o **Autor** pelo **GitHub**: [@C4Adriano]

## American English <a id="en-us">(en-US)</a>

### Supported Versions

Only the latest minor release of the current major version receives security attention.

| Version | Supported |
| ------- | --------- |
| 7.x.x   | ✅        |
| < 7.0.0 | ❌        |

### Current Version

This **Software** currently runs entirely in the browser with no external server, no **User** data, and no external connections, so security vulnerabilities are unlikely.

If you find something in the current **Version**, open an **[Issue]**. As this is a solo-maintained project, please allow up to **14 days** for a response.

> **Note:** Including code excerpts in an **[Issue]** on this repository, strictly for the purpose of reporting or discussing a vulnerability, is not considered use, copying, or distribution of the **Software**, as provided in [Section 4][License-§4] of the **[License]**, which also sets the limits of this exception.

### Future Versions

Future **Versions** may include **User** accounts and data storage.
When that happens, this policy will be updated — and vulnerabilities involving **User** data should **NOT** be reported publicly.

Until then, if in doubt, contact the **Author** directly via **GitHub**: [@C4Adriano]
