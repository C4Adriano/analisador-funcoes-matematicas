### 📐 Mathematical Terms

**Asymptote**
A line that a curve approaches but never touches. In Exponential and Logarithmic Functions, the asymptote defines the boundary of the function's range.

**Coefficient**
A number that multiplies a variable in a function. In `f(x) = ax² + bx + c`, the coefficients are `a`, `b`, and `c`.

**Concavity**
Describes whether a Quadratic Function opens upward (happy face, `a > 0`) or downward (sad face, `a < 0`).

**Domain**
The set of all valid input values (`x`) for a function.

**Range**
The set of all output values (`y`) produced by a function. Also called _Image_.

**Root**
A value of `x` where `f(x) = 0` — that is, where the function crosses the X axis.

**Sign Study**
An analysis that determines for which values of `x` the function is positive, negative, or zero.

**Vertex**
The highest or lowest point of a Quadratic Function. Defined by the coordinates `(-b/2a, -Δ/4a)`.

**Slope**
Describes how steep a Linear or Exponential Function is. In a Linear Function, it is the coefficient `a` in `f(x) = ax + b`.

**Unknown**
A coefficient (`a`, `b`, or `c`) whose value is not given directly — the program calculates it from known points.

### 💻 Code Terms

**Object**
A JavaScript structure that groups related functions and variables together. This project uses objects like `config`, `helpers`, `algebra`, and `analisar` to organize the code.

**JS Function**
A block of reusable code in JavaScript that performs a specific task. Different from a Mathematical Function.

**`config`**
The object that stores all global program settings, such as decimal places, language, and Unicode preferences.

**`helpers`**
The object that contains common calculations and result assembly used across multiple function types.

**`algebra`**
The object responsible for mathematical calculations such as logarithms, natural log, and safe division.

**`analisar`**
The object that handles the analysis of each mathematical function type.

**`escrita`**
The object responsible for formatting, translating, and converting text for display.

**`ui`**
The object that manages user interaction — menus, inputs, and error display.

**`erro`**
The object that provides standardized error messages throughout the program.

**`prompt`**
A built-in browser dialog that asks the user to type a value. Used as the main input method in this project.

**`alert`**
A built-in browser dialog that displays a message to the user. Used to show results and menus.

**`NaN` (Not a Number)**
A JavaScript value that appears when a mathematical operation produces an invalid result, such as dividing zero by zero.

**`Infinity`**
A JavaScript value that appears when a number exceeds the maximum representable value, such as dividing by zero.

### 🐙 GitHub Terms

**Branch**
A parallel version of the repository. The main branch is called `main`.

**Changelog**
A file that documents all changes made across versions of the project. See [`CHANGELOG.md`](https://github.com/C4Adriano/analisador-funcoes-matematicas/blob/main/CHANGELOG.md).

**Commit**
A saved snapshot of changes in the repository. Each commit has a message describing what was changed.

**Fork**
A personal copy of someone else's repository, allowing you to make changes without affecting the original.

**Issue**
A report or suggestion submitted through GitHub. Can be a bug report or a feature request.

**Pull Request (PR)**
A proposal to merge changes from one branch into another. Used for code review and contributions.

**Release**
A published version of the project, marked with a version tag (e.g., `v6.0`).

**Repository**
The project folder hosted on GitHub, containing all files, history, and settings.
