### 📐 Mathematical Terms

**Amplitude**
The maximum distance a periodic **Function**'s graph deviates from its central axis. In `f(x) = a · sin(x)`, the **Amplitude** is `|a|`.

**Asymptote**
A line that a curve approaches but never touches. In **Exponential** and **Logarithmic Functions**, the **Asymptote** defines the boundary of the **Function**'s range.

**Coefficient**
A number that multiplies a variable in a **Function**. In `f(x) = ax² + bx + c`, the coefficients are `a`, `b`, and `c`.

**Concavity**
Describes whether a **Quadratic Function** opens upward (_happy face_, `a > 0`) or downward (_sad face_, `a < 0`).

**Domain**
The set of all valid input values (`x`) for a **Function**.

**Period**
The length of one complete cycle of a periodic **Function**, such as **Sine, Cosine**, or **Tangent**.

**Range**
The set of all output values (`y`) produced by a **Function**.

**Root**
A value of `x` where `f(x) = 0` — that is, where the **Function** crosses the **X-axis**.

**Sign Study**
An analysis that determines for which values of `x` the **Function** is positive, negative, or zero.

**Vertex**
The highest or lowest point of a **Quadratic Function**. Defined by the coordinates `(-b/2a, -Δ/4a)`.

**Slope**
Describes how steep a **Affine Function** is. In a **Affine Function**, it is the coefficient `a` in `f(x) = ax + b`.

**Unknown**
A coefficient (`a`, `b`, or `c`) whose value is not given directly — the **Program** calculates it from known points.

### 💻 Code Terms

**Object**
A **JavaScript** structure that groups related **JS Functions** and variables. This **Project** uses objects like `config`, `helpers`, `algebra`, and `analyze` to organize the code.

**JS Function**
A block of reusable code in **JavaScript** that performs a specific task. Different from a **Mathematical Function**.

**`algebra`**
The object responsible for **Mathematical** calculations, such as logarithms, natural log, and safe division.

**`analyze`**
The object that performs the analysis of each type of **Mathematical Function**.

**`checks`**
The object responsible for type-checking utilities used across the **Project**'s `.ts` files. Written in **TypeScript**.

**`commands`**
The object that manages the **Program**'s commands.

**`config`**
The object that stores all global **Program** settings, such as decimal places, language, and **Unicode** preferences. Written in **TypeScript**.

**`error`**
The object that provides standardized error messages throughout the **Program**. Written in **TypeScript**.

**`helpers`**
The object that contains common calculations and result assembly used across multiple types of **Function**.

**`i18n`**
The object that provides the **Program**'s language **Functions** _(internationalization)_. Written in **TypeScript**.

**`main`**
The object that orchestrates the **Program**, initializing and coordinating the other objects.

**`state`**
The object responsible for managing the **Program**'s state. Written in **TypeScript**.

**`ui`**
The object that manages user interaction — menus, inputs, and error display.

**`values`**
The object that defines the shared types used across the **Project**'s `.ts` files. Written in **TypeScript**.

**`**Version**`**
The object that stores the **Program**'s current **Version**.

**`writing`**
The object responsible for formatting, translating, and converting text for display.

**`prompt`**
A native browser dialog that asks the user to type a value. Used as the main input method in this **Project**.

**`alert`**
A native browser dialog that displays a message to the user. Used to show results and menus.

**`NaN` (Not a Number)**
A **JavaScript** value that appears when a **Mathematical** operation produces an invalid result, such as dividing zero by zero.

**`Infinity`**
A **JavaScript** value that appears when a number exceeds the maximum representable value, such as dividing `x` by zero.

### 🐙 GitHub Terms

**Branch**
A parallel **Version** of the repository. The main branch is called `main`.

**Changelog**
A file that documents all changes made across versions of the **Project**. See **[`Changelog`](https://github.com/C4Adriano/analisador-funcoes-matematicas/blob/main/docs/CHANGELOG/CHANGELOG_EN.md)**.

**Commit**
A saved snapshot of changes in the repository. Each commit has a message describing what was changed.

**Fork**
A personal copy of someone else's repository, allowing you to make changes without affecting the original.

**Issue**
A report or suggestion submitted through **GitHub**. Can be a bug report or a feature request.

**Pull Request (PR)**
A proposal to merge changes from one branch into another. Used for code review and contributions.

**Release**
A published **Version** of the **Project**, marked with a **Version** tag _(e.g., `v6.0.0`)_.

**Repository**
The **Project** folder hosted on **GitHub**, containing all files, history, and settings.
