# Convenções de Nomenclatura

## Variáveis e Funções

- camelCase para variáveis e funções: `tipoFuncao`, `pedirCoefs`
- Funções nomeadas com verbos: `analisar()`, `exibir()`, `calcular()`

## Constantes

- UPPER_CASE para constantes globais: `VERSAO`, `IDIOMA_PADRAO`

## Arquivos

- camelCase para arquivos JS: `algebra.js`, `analisar.js`
- UPPER_CASE para documentação: `CONTRIBUTING.md`, `CHANGELOG.md`

## Commits

- Seguir Conventional Commits: `feat:`, `fix:`, `docs:`, `chore:`
